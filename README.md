**Palmera Bay** — an original open-world crime game. Rico Vega owes the fixer Marla Quinn $5,000. Explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police, and work off the debt across three story missions: a car boost for the spray shop, a timed courier run across town, and a bank vault job with a three-star getaway. Traffic, pedestrians, a wanted level with pursuing cruisers and armed officers, combat, a HUD with a live minimap, and automatic saving — all in plain static files, no network, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `game/` with any static file server and open `index.html`.

## Controls

- **Enter** start / continue, **WASD** walk and drive, **Shift** run, **Space** handbrake
- **E** enter or steal a car, start a job at the garage
- **Mouse** aim, **click** shoot, **F** punch, **R** reload
- **P** pause, **M** mute
